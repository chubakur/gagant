# Гант-планировщик (gagant)

Помощник планирования проекта по диаграмме Ганта. **Frontend-only**: без бэкенда и БД,
все данные хранятся в браузере (localStorage) и переносятся экспортом/импортом JSON.

## Возможности

- **Проекты, команды, задачи.** У команды задаётся ёмкость (единиц работы в день).
- **Задачи**: оценка в единицах работы, команда-исполнитель, зависимости от других задач,
  необязательная минимальная дата старта.
- **Автоматический пересчёт.** Любое изменение (оценка, команда, зависимости, ёмкость,
  дата старта, минимальная дата) немедленно перестраивает диаграмму.
- **Оптимальный план.** Жадное планирование по дням с учётом ресурсов команды:
  задачи критического пути получают ёмкость первыми, внутри дневной ёмкости команды
  возможна параллельная работа.
- **Детект циклов** в зависимостях — с понятным сообщением вместо зависания.
- **Экспорт/импорт** описания команды, проектов и задач в JSON.
- Учёт рабочих дней (опция «выходные» исключает сб/вс).

## Модель данных

    project { id, name, description, startDate, skipWeekends, teams[], tasks[] }
    team    { id, name, capacity }              // capacity — единиц работы в день
    task    { id, teamId, title, description, estimate, dependencies[], minStart }

Даты начала/окончания задач — вычисляемые (в localStorage не хранятся).

## Как пользоваться

1. Добавьте команды и задайте ёмкость (например, 2 ед/дн).
2. Добавьте задачи: оценку, команду, зависимости.
3. Меняйте оценки/зависимости/ёмкость — гант перестроится сам.
4. «Экспорт» сохраняет JSON на диск, «Импорт» добавляет проекты из файла.

## Локальный запуск

Используются обычные script-теги (без ES-модулей), поэтому страницу можно открыть
файлом index.html. Для корректной работы localStorage лучше поднять статический сервер:

    python3 -m http.server 8000

и открыть http://localhost:8000/
